# Age-Based Diet Game 

An interactive nutrition game built with React where users enter 
their age to get their recommended daily calorie intake and build 
a balanced meal by dragging food items onto a plate.

## Features
- Age-based calorie calculator
- 10 Indian food items with calorie values
- Track food groups used (target: 4/4)
- Real-time calorie counter
- Interactive plate system

## Tech Stack
- React
- CSS
- Deployed on Vercel

## What I learned
- React state management
- CSS styling and layouts
- Deploying with Vercel
